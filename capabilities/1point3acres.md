# 1point3acres

## CLI boundary

The CLI offers no functionality to access or write 1point3acres. A human must always perform login. After login, a browser/computer-use agent may continue the requested work in that same context when automation is available; otherwise the human follows this procedure. The user owns the final publication decision.

## Authentication

Ask the human to log in at `https://www.1point3acres.com/` and complete any challenge. Preserve that browser context and confirm the authenticated composer is interactive before drafting. Return to the human if login or a challenge blocks progress.

## Platform specification and gotchas

- `workplace-reflection`: 职场达人, [forum 98](https://www.1point3acres.com/editor/thread?fid=98&from=home), for workplace/career reflection. A theme is required; use 职场感言 when appropriate, or choose from the live options.
- `chinese-life`: 海外生活 / 华人生活, [forum 29](https://www.1point3acres.com/editor/thread?fid=29&from=home); referrals and rental ads belong elsewhere.
- `job-search`: 海外求职 / 求职（非面经）, [forum 28](https://www.1point3acres.com/editor/thread?fid=28&from=home); requires theme, year, job category, major, and experience range. Interview experience, referrals, salary, technical, and OPT/H1B topics have dedicated forums.
- For any other destination, inspect the live forum/category, rules, theme, and required metadata before drafting.
- This procedure covers text-only Markdown posts. The observed title counter has a weighted maximum of 40; obey the live counter rather than estimating from character count. The body maximum is unknown.
- Choose 保存草稿, then reopen the entry from 草稿箱 in the same browser and compare the full title and body before reporting a saved draft. A save-success indicator alone is insufficient. If saving is uncertain, inspect the draft box before retrying. Stop before 发布帖子 unless publication is explicitly authorized and can be verified live.
